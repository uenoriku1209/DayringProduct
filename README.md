# DayRing

デスクトップに置ける、枠のない角丸の小さなウィジェットアプリです（Electron + React + TypeScript）。

## 機能

| 機能 | 内容 |
| --- | --- |
| **時計** | 日付・曜日・時刻（秒つき）と、今日の経過を示すバー。予定の最中は「いまの予定・残り時間」も表示 |
| **予定（24 時間の円グラフ）** | リングの空いているところをドラッグすると、その時間帯で予定を作成（15 分単位）。「予定を追加」からも作れる。予定を押すと編集・削除。重なる予定は作れない。毎日同じ時間に表示 |
| **予定の開始・終了** | 開始時刻になると、ウィジェット全体に泡の演出（シャボン玉のような START の玉がふわりと浮かび、まわりを小さな泡がゆっくり上っていく。タイトルは 1 文字ずつ静かに浮かび上がる）を表示し、そのあと円グラフの中央に予定の内容と終了までの残り時間（カウントダウン）を表示。いまの予定は少し外側に浮き上がり、残りの部分に光が流れる。終了 5 分前は黄色で「まもなく終了」、終了時は泡の中に ✓ が描かれ「おつかれさま」 |
| **水が溜まる演出** | 1 日の経過とともに、ウィジェットの下から淡い水が少しずつ溜まっていく（ゆっくり流れる波と小さな泡）。予定の最中は、円グラフの中央にも予定の色の水が進み具合に合わせて溜まる。設定でオフにできる |
| **目標** | 期間（今日・3日・1週間・2週間・1か月、または日付指定）つきで目標を作成。達成したらチェック（+点数が飛び出す）。これから始まる目標・期限切れの目標も分けて表示（期限切れは「1 週間延ばす」も可） |
| **習慣（無期限）** | 「筋トレを続ける」「お菓子を食べない」のような期限のない習慣を、チェックが必要な日（毎日 / 曜日指定（例: 月・水・金） / 1日おき・2日おき・3日おき・週に1回）を決めて登録。必要な日にチェック（+3 点）。続けてできている回数（○回連続）と直近 14 日の記録を表示し、記録の点を押せば付け忘れた日もチェックできる。チェックが不要な日は「今日はお休み・次は○日」 |
| **スコア** | 目標 1 つで 10 点 ＋ 期間 1 週間ごとに 5 点（最大 +30）、習慣のチェック 1 回で 3 点。その月の合計が「月のスコア」で、毎月 1 日に 0 から始まる |
| **成長** | 今月のスコア（目標の達成数・習慣のチェック回数）・ランク（スタート → ブロンズ → シルバー → ゴールド → プラチナ → ダイヤ）・先月比と、スコアに応じた一言。年間の推移（月ごとの棒グラフ＋年間の累計の線）、年間合計・目標の達成・習慣のチェック・最高の月 |
| **ウィジェットとして** | 上部をドラッグで移動、右下の角で大きさを変更（位置と大きさは保存）。常に手前に表示、PC 起動時の自動起動、ダーク / ライト、背景の濃さ、予定開始時の Windows 通知。× ではなく「−」でタスクトレイにしまい、トレイのアイコンか **Ctrl+Alt+D** で再表示 |

## 使い方

```bash
npm install
npm run dev        # 開発モードで起動
npm run build:win  # Windows 用インストーラー (dist/DayRing-1.0.0-setup.exe) を作成
```

- 終了するには、タスクトレイのアイコンを右クリック →「終了」、または設定画面の「終了」。
- データは `%APPDATA%\DayRing\dayring.json` に保存されます（バックアップしたいときはこのファイルをコピー）。
- 予定の演出や通知は、アプリが起動している間（トレイにしまっていても OK）に表示されます。

## ファイル構成

```
src/main/index.ts                 … ウィンドウ（枠なし・透明）、トレイ、ショートカット、自動起動
src/main/store.ts                 … データ・ウィンドウ位置の保存
src/preload/index.ts              … 画面に公開する API
src/shared/types.ts               … データの型
src/renderer/src/App.tsx          … 画面全体
src/renderer/src/components/
  ClockCard.tsx                   … 日付・時刻
  Donut.tsx                       … 24 時間の円グラフ（ドラッグで作成・針・中央の表示）
  PlanView.tsx                    … 予定の編集・一覧
  PlanEvents.tsx                  … 予定の開始・終了の演出
  GoalView.tsx                    … 目標（期間つき）と、習慣への切り替え
  HabitView.tsx                   … 習慣（無期限）
  Water.tsx                       … 水が溜まっていく演出
  GrowthView.tsx                  … スコア・ランク・年間の推移
  SettingsPanel.tsx               … 設定
src/renderer/src/lib/
  plans.ts                        … 円グラフの計算・予定の重なり判定
  score.ts                        … 点数・ランク・一言
  habits.ts                       … 習慣のチェックが必要な日・連続回数
  usePlanEvents.ts                … 予定の開始・終了の検出と通知
src/renderer/src/assets/app.css   … 見た目とアニメーション
```

## カスタマイズのヒント

- 点数の付け方: `src/renderer/src/lib/score.ts` の `goalPoints`、習慣は `src/renderer/src/lib/habits.ts` の `HABIT_POINTS`
- 水の濃さ・波の速さ: `src/renderer/src/assets/app.css` の「時間とともに溜まっていく水」
- ランクの境目と一言: 同じファイルの `RANKS` と `COMMENTS`
- 予定の色: `src/renderer/src/lib/plans.ts` の `PLAN_COLORS`
- 演出の長さ: `src/renderer/src/components/PlanEvents.tsx` の `START_MS` / `END_MS`
- 表示・非表示のショートカット: `src/main/index.ts` の `SHORTCUT`
